無障礙聲明

本網站遵循國家通訊傳播委員會 (NCC) 及數位發展部頒布之《無障礙網頁開發規範 2.1》進行架構設計，致力於確保網頁內容符合最高等級 AAA 級規範。本站所有頁面均可以透過純鍵盤操作，並支援螢幕閱讀器等各類輔助技術使用。

一、 快捷鍵 (AccessKey) 操作說明

本網站依據無障礙網頁設計原則，於各主要導覽區域設置定位點 `:::` 及快捷鍵。您可以使用鍵盤按鍵搭配快捷鍵快速移至目標區塊：

  • Alt + U：定位於上方頁頭與主導覽選單區塊，包含網站標題與主要導覽連結。
  • Alt + C：定位於中央主要內容區塊，跳過選單直接瀏覽各頁面的核心資訊。
  • Alt + Z：定位於下方頁尾資訊區塊，包含網站宣告、聯絡方式與無障礙標章資訊。

不同瀏覽器操作方式說明：
• Chrome / Edge / Safari：`Alt + 快捷鍵字母`
• Firefox：`Alt + Shift + 快捷鍵字母`
• Mac 操作系統：請將 `Alt` 鍵改為 `Control + Option` 鍵組合。

二、 無障礙設計特色

  • 高視覺色彩對比：全站文字與背景對比度均達 7:1 以上，符合 AAA 級弱視友善規範。
  • 清晰的鍵盤聚焦框：全站所有可按壓元件與超連結在取得焦點時，均會呈現 4px 粗橘紅色高亮邊框。
  • 可縮放文字排版：全站使用相對單位（rem），使用者可透過瀏覽器放大至 200% 以上，排版結構依然清晰不破版。
  • 語意化結構：完整導入 HTML5 語意標籤與 ARIA 無障礙屬性，便利螢幕閱讀器使用者理解網站大綱。

三、 無障礙標章認證等級

本網站目前符合《無障礙網頁開發規範 2.1》最高等級 AAA 級標章 認證標準。
